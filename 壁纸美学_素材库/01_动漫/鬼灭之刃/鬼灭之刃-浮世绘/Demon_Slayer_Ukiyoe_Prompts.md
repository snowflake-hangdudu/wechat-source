## 使用方法

生成单张人物图时，依次组合 **通用母提示词（Master Prompt）＋指定角色提示词（Character Prompt）＋负面提示词（Negative Prompt）**。上传原始参考图时，请标注为 **style reference only**，不要复制《火影忍者》人物。每次只生成一名角色，不要拼成八宫格。

**系列视觉重点：**樱花、紫藤、蝶纹与和服织物；保留鬼杀队制服、武器及人物发饰。

## 四、出图一致性规范

- 画面：独立单人竖屏，建议 **9:16**；主体清晰，采用优雅半身、四分之三身或自然全身构图。
- 固定风格：做旧和纸纸纹、木版印刷颗粒、樱花、海浪、朱红日轮、日式流云和低饱和色系。
- 人设要求：保留人物特有的发型、瞳色、配饰、服装、象征性武器或能力；允许服装细节有版画化纹理，不要换成千篇一律的和服。
- 建议顺序：`Master Prompt → Character Prompt → Negative Prompt`。
- 备注：这是一套以已生成图为依据整理的二创提示词，不保证不同模型复现完全一致的画面。
