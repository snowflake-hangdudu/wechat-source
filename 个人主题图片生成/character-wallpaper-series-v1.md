# 女性角色壁纸美学 · 个人专场 V1

版本：1.1（新增跨会话启动口令、画风 Skill 链接和参考图锚点）

定位：成年女性角色的个人主题壁纸专场。用相同的审美与质检标准，针对不同角色重配场景与服装；默认 20 张，数量可调整。

参考画风体系：https://github.com/yang0/handraw-style

## 一、统一审美与不可妥协的边界

系列审美关键词：成熟丰盈、曲线协调、含蓄性感、知性优雅、衣着得体、自然生动。

1. 人物明确为成年版本；保持对应作品中的发色、眼睛、五官、标志性细节和人格气质。角色辨识度优先于穿搭。
2. 成年女性可以有自然丰盈的胸部和胸腰臀曲线，但身体尺寸必须与肩宽、骨盆、身高协调。不为了放大胸部而改变胸廓、脊柱和手臂结构。
3. 含蓄性感主要来自合身剪裁、布料垂坠、领口层次、腰线、站姿和眼神。丝袜、丝巾、薄纱袖口、耳饰可选；不强制露肤，也不使用透视敏感区域、刻意走光或裸露博取注意。
4. 动作必须由真人自然完成：肩胯方向合理，关节完整，双手手指数目正确，身体重心有支撑。不要夸张扭腰、悬空坐姿或不能解释的肢体交叠。
5. 单图独立成品；不在画面添加编号、标题、解释字、拼贴框或水印；不裁切原图。默认竖版 2:3，如需专门手机屏幕可换 9:16 并重新构图，不强制裁原图。
6. 同一角色专场必须有不同服装、行为、情绪、视角与色彩。即使重复海港、花卉或和服，也要做到场景功能和行为明显不同。

## 六、可替换的成年角色卡

### Nami / 娜美（成年）
- 必留识别：橙色长发、棕色眼睛、聪明自信的航海士气质；服装自然允许时可露出上臂蓝色纹身。
- 核心主题：航海、海图、罗盘、晴雨海港、沿海旅行、船舱。
- 情绪：聪明、从容、温暖、偶尔俏皮。
- 配色：海蓝、青绿、奶油白、珊瑚橙、酒红。

### Hinata Hyuga / 日向雏田（仅成年版本）
- 必留识别：深蓝黑长发、浅紫白眼、温柔而坚定的气质；成熟版本的面容与身体比例。
- 核心主题：木叶庭院、林荫、山茶、月色、茶室、修行后的平静；适量忍者元素。
- 情绪：温柔内敛、自信成长、静谧勇气。
- 配色：藕紫、靛蓝、灰蓝、暖白、藤花紫。
- 不要把娜美的海图、罗盘、航海日常强行转移到雏田身上。

### Boa Hancock / 波雅·汉库克、女帝（成年）
- 必留识别：长黑发、深色眼睛、修长优雅的成年女性面容、标志性金色蛇形耳饰、女王般的自信。
- 核心主题：宫殿长廊、海边露台、花园、礼服、典雅宴会、岛屿女王与海洋元素。
- 情绪：高贵、从容、独立、柔和时仍有女王气场。
- 配色：深酒红、象牙白、黑金、翡翠绿、紫色。
- 不要把女帝画成橙发娜美或普通时装模特。

## 九、验收门槛与批次节奏

每张图检查四项，各 0–5 分：

1. 身份辨识（0–5）：角色不可串脸、串发色、串标志饰品。
2. 人体解剖（0–5）：肩胯和胸腰臀合理、坐站行走可实现、手脚完整。
3. 画风忠实（0–5）：FD-026 留白、细线、淡彩；其他画风各有媒介特征。
4. 主题独特（0–5）：服装、行为、情绪、背景不要与相邻图重复。

原则：总分至少 17；身份与人体各不低于 4。出现不合理扭曲、刻意色情化、漏肢/多指或错误角色身份时直接返工。

制作节奏：规划总表 → 每批 3 张独立生成 → 查看图片并打分 → 锁定合格图 → 只重做问题图 → 继续下一批 → 完整专场 20 张终审。总数 20 可以换成 12、24 或自定义 N；每张均保持独立。
